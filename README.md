# Morenoseguros · Datos

**Un proyecto de Fabricio Moreno · Morenoseguros**

Visualizaciones de datos sobre el mercado de seguros en Argentina, pensadas para pymes y profesionales independientes.

Cada proyecto parte de una pregunta concreta, usa datos públicos y verificables, y explica en lenguaje simple qué significa para quien tiene que tomar decisiones sobre sus seguros.
